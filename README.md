# 📝 ToDo - Always Go

A modern and minimal **ToDo app** built with **ReactJS**, **JavaScript**, and **CSS**.  
Manage your daily tasks with an intuitive drag & drop interface, local storage, and smart batch controls — all wrapped in a clean, responsive UI.

---

## 🚀 Features

- ✅ Add, edit, and delete tasks  
- 🏷️ Mark all tasks as completed  
- 🗑️ Drag & drop tasks into the trash bin to delete  
- 💾 Tasks automatically saved in **localStorage**  
- 🌙 Modal confirmation for deleting all tasks  
- 📱 Responsive and minimal design  
- ⚡ Built with **Vite** for fast development

---

## 🧰 Tech Stack

- **ReactJS**
- **JavaScript (ES6+)**
- **CSS (custom styling)**
- **Vite** (build tool)

## ⚙️ Installation & Setup

Clone this repository and run the following commands:

```bash
git clone https://github.com/your-username/todo-always-go.git
cd todo-always-go
npm install
npm run dev
```

Then open your browser at the link shown in the terminal  
(usually [http://localhost:5173/](http://localhost:5173/)).
